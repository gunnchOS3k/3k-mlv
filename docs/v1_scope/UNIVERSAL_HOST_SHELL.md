# Universal Host Shell (3k MLV)

3k MLV is a host-neutral game-like shell above supported host operating systems.

```text
3k MLV CORE
↓
HOST CAPABILITY CONTRACT
↓
HOST ADAPTER
↓
HOST OPERATING SYSTEM
```

- Core world routes (Home, Campus, Gallery, WAIKE, Network Twin, launch intents, privacy, session navigation) must not hard-depend on gunnchOS-only APIs.
- gunnchOS remains the deepest first-party integration.
- Support matrix is evidence-based; do not claim every OS.
